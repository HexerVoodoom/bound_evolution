## Convenções

- O documento mestre deve refletir o estado real do projeto.
- Não registrar uma implementação como concluída sem verificar código e testes.
- Marcar claramente decisões **CONFIRMADAS**, **PROPOSTAS**, **PROVISÓRIAS** e **EM ABERTO**.
- Ao criar novas especificações, usar nomes versionados e adicionar uma linha nesta tabela.
- Quando uma decisão for alterada, atualizar o handoff e registrar a razão.
